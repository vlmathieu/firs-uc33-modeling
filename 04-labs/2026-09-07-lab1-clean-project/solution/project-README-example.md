# Lab 1, step 7 — a model README

This is what the `README.md` **at the root of your `uc33-lab1/` folder** should look
like. It is deliberately short. Everything below the horizontal rule is the file
itself; copy the shape, not the words.

Three questions, three answers. Nothing else is required, and anything else you add
must earn its place.

---

# uc33-lab1

French roundwood trade, UN Comtrade extract 2022-2024. Lab 1 of UC 3.3 Modeling,
7 September 2026.

## Requirements

R (>= 4.0) and the `here` package: `install.packages("here")`.

## How to run it

Open `uc33-lab1.Rproj` in RStudio, then run `src/01_import.R`. It reads
`data/raw/comtrade_fr_roundwood_clean.csv` and writes
`data/processed/trade_france.csv` (361 rows).

Data in `data/raw/` is read-only. Everything in `data/processed/` and `output/` is
regenerated by the scripts and can be deleted.

## Why those lines and not others

| The reader's question | The line that answers it | What happens without it |
|---|---|---|
| What is this? | The title and the one-sentence description | They open every script to find out |
| Can I run it? | The requirements | They run it, hit `there is no package called 'here'`, and guess |
| What do I run, and in what order? | The *How to run it* section | They open `01_import.R` and hope it is the entry point |
| Did it work? | **361 rows** | They have no way of knowing their run was correct |

That last row is the one nobody writes and everybody needs. A README that states the
expected result turns "it ran" into "it ran correctly" — and it is the same reflex as
lab 3's script 5: knowing what the answer should look like before you compute it.

## What does not belong in it

- Your name and the date at the top: git records both, from 20 October.
- A description of every function in the script: that is what comments are for, and
  they rot in a different place from the code they describe.
- A list of every file in the folder: the folder is the list of the files in the folder.
- "Work in progress". Everything is.

## The test

Your partner has your folder, no explanation, and no right to ask you a question.
**Read your README as if you were them.** If a single step is missing, they stop there
— and step 8 is exactly that experiment, run for real.
