# Model cartography

The assessed deliverable of the course unit, due **15 January**, in pairs. It is 40 % of the mark.

The task is to survey and analyse, against a shared grid, the models encountered across the whole programme — not only in this course unit.

Three things are handed in: the cartography itself, as one A3 page; a three-page synthesis note; and the filled grid, as an annex. [`guidance-note.md`](guidance-note.md) says what each is for.

**Expected here:**

| File | Purpose |
|---|---|
| [`guidance-note.md`](guidance-note.md) | What is expected, in what form, with references to existing model typologies to draw on |
| [`analysis-grid.csv`](analysis-grid.csv) | The analysis grid, as a fillable template |
| `worked-example.md` | One model sheet, fully filled in, to copy |
| [`assessment-criteria.md`](assessment-criteria.md) | The assessment criteria |
| [`typology-references.md`](typology-references.md) | Annotated bibliography: description protocols, ecological and economic model typologies |

*Four of the five are available.*
*`worked-example.md` is still being written; until it is there, slide 12 of the opening session plays its role, and the grid ships with that same example already filled in.*

**Read the guidance note**, and preferably early, to leave time to digest it.

The deliverable is sent by email, as set out in the guidance note.
